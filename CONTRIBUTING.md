# Contributing to Tomo

Thanks for helping. This page is short on purpose.

## Reporting

All reports from every browser and system go to this repository, in the [issue tracker](https://github.com/C-Rosende/Tomo/issues/new/choose).

- **Bug:** use *Report a problem*, or the button in Tomo's settings. Describe what happened and select your system and browser. Diagnostics and screenshots are optional. Review them for private information before sharing.
- **Idea or question:** use *Suggestion or question*. Read the [FAQ](FAQ.md) first.
- **One problem per issue.** Search open and closed issues before opening a new one.
- **Security:** do not open a public issue. See [SECURITY.md](SECURITY.md).

## Labels

| Label | Meaning |
|---|---|
| `os: windows`, `os: macos`, `os: linux` | System of the reporter |
| `browser: firefox`, `browser: chrome`… | Browser of the reporter (added automatically) |
| `bug`, `suggestion` | Type |
| `needs info` | A maintainer has asked for more information |
| `help wanted`, `good first issue` | Open to contributors |

## Code changes

Development and its history are maintained in a private repository. This public repository contains installation instructions, releases, legal documents and support.

Report bugs, suggest improvements, help test a fix or propose a documentation correction here. Contact the maintainer through an issue before proposing code changes. Do not include private source, credentials or personal diagnostics in a public pull request.
