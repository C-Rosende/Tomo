# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, the steps to reproduce it and the Tomo version.

You can expect an answer within a few days. Once a fix is released, the report can be made public with credit to you if you want it.

## Supported versions

Only the latest release gets fixes.

## Scope

In scope: the extension, the local component (`backend/`) and the installers. Out of scope: problems in third-party tools such as yt-dlp or FFmpeg (report those to their projects) and sites that block downloads.

See the [privacy policy](PRIVACY.md) and [permissions](docs/permissions.md) for how Tomo handles data and browser access.
